# Campus Management Solution (Java + Oracle Database)

A Campus Management System built as a semester project, using JavaFX for the desktop UI and an Oracle database for data storage.

## Tech Stack

- **Java** / **JavaFX**
- **Oracle Database** (via JDBC)

## Getting Started

### Prerequisites

- JDK 8+ with JavaFX support
- Oracle Database (local instance or Oracle Express Edition)
- NetBeans or Eclipse

### Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Ahmeds168/Campus-Management-Solution-Using-Oracle-Database-in-Java.git
   ```
2. In NetBeans or Eclipse, create a new empty **JavaFX** project and import the contents of the `CMS (using oracle sql database)` folder into it.
3. Configure your Oracle database connection details (JDBC URL, username, password) in the project's connection/config file.
4. Build and run the project from your IDE.
